Nothing you type here is transmitted anywhere

This is a portfolio demo of a fictional business. The form below is a styled mock. It has no action, posts to no server, sets no cookie and stores nothing, in the browser or elsewhere. Please do not enter real personal or financial information.

The HubSpot portal ID and form GUID in js/hubspot-form.js are placeholders. Replace both, as described in the README under Configuration, and the genuine HubSpot embed mounts in place of this mock automatically. No other edit is required, and the attribution logic below is the same code either way.
