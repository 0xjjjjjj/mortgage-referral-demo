Referral portal demo

Hand your buyer a link. We take it from there.

Meadowbrook Mortgage Demo shows how a small mortgage branch gives its real estate agent partners a personalized landing page for every buyer they refer, routed to a named loan officer and tracked end to end.

Start an application I'm a real estate agent

How the referral flow works

Three steps, no login, no app to install. The whole path from text message to submitted application is a handful of static pages and one form.

  1. Step one

    The agent shares a link

    Every partner agent gets a short vanity URL. Sending /sarah to a buyer redirects them to a landing page already scoped to that loan officer.

  2. Step two

    The buyer sees their name

    The landing page reads the referring agent and loan officer straight from the URL and greets the buyer by name, so the handoff feels personal instead of generic.

  3. Step three

    Attribution follows them

    Both values ride along to the application form and land in hidden fields, so every submitted lead records which agent sent it and which officer owns it.

See a live personalized landing page — try editing the agent and lo parameters in the address bar.

Built for the way agents actually work

Agents send links from their phone, standing in a driveway, between showings. So the pages are static, mobile-first, and load in well under a second on a cellular connection.

Read the partner overview

  • Short links per officer

    Vanity redirects like /sarah and /marcus fit in a text message and survive being retyped.

  • Graceful when it goes wrong

    A misspelled or missing parameter falls back to a generic welcome. The buyer never sees an error.

  • Measured end to end

    Apply, Call, Text and form submission each fire a distinct analytics event, so the funnel is legible.
