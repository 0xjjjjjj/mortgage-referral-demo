About us

A small branch built around one relationship: yours with your agent

Meadowbrook Mortgage Demo is a fictional mortgage branch serving DuPage County, Illinois. This site is a portfolio demo showing how a small branch could hand every referral a personalized, trackable landing page instead of a generic phone number.

Who we serve

The fictional Meadowbrook branch is written to serve buyers across DuPage County: Naperville, Wheaton, Downers Grove and the surrounding suburbs. Buyers usually arrive by way of a real estate agent who already knows them, not a cold search, so the branch is built around agent partnerships rather than paid lead generation. First-time buyers, move-up buyers, self-employed borrowers and investors are all represented among the three fictional loan officers on the team.

Why the referral model exists

A buyer who gets a text from their agent saying "call Sarah, she's expecting you" starts the mortgage conversation already trusting the referral. Most small-branch websites break that trust the moment the buyer lands on a generic homepage with no names on it. This demo exists to show the alternative: a link that already knows which agent sent the buyer and which loan officer is waiting for them, so the page can greet both by name and the buyer never has to re-explain who referred them.

Everything downstream follows the same idea. The application stub carries the agent and loan officer forward in hidden fields, so a submitted lead always records where it came from, without asking the buyer to fill in one extra box.

How we work with agent partners

Each fictional loan officer gets a short vanity link, and each agent can layer their own name on top of it with a single URL parameter. There is no login, no app to install, and no portal to remember a password for. An agent standing in a driveway between showings can send a link from their phone in a few seconds.
