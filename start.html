This page is built from the link you followed

The greeting above is assembled from two query-string parameters: agent, the name of the real estate agent who referred you, and lo, the short slug for a loan officer. Try editing them in the address bar. ?agent=Dana%20Whitfield&lo=sarah becomes a welcome from Dana Whitfield routed to Sarah Chen; swap sarah for marcus or jordan and the page changes with it.

What happens when the link is wrong

Referral links get retyped, truncated by messaging apps and forwarded on. Four separate things can go wrong here, and all four land in the same place: the generic welcome you would see with no parameters at all. Nothing on this page renders an error message to the buyer.

  • Missing parameter. No agent means the referral clause is simply omitted. No lo means no officer is named.
  • Misspelled parameter. Anything outside letters, digits and spaces is stripped before it reaches the page, so a mangled value degrades to a shorter one or to nothing.
  • Unknown officer. A slug that matches no one on the team resolves to no officer, the card stays hidden, and the welcome stays generic.
  • Failed lookup. If the officer data never loads, the copy already in the HTML stands as written. The failure is logged for a developer and is invisible to the buyer.
